# 🪷 Gokul Marriage Hall Website

A luxury and fully responsive wedding venue website developed for **Gokul Marriage Hall** using **HTML, CSS, and JavaScript**.  
This project is designed to showcase the elegance, facilities, and atmosphere of the venue through a modern and visually immersive user interface.

The website provides visitors with a complete overview of the marriage hall, including venue details, image gallery, amenities, virtual tour section, and booking/contact information — all presented with smooth animations and an elegant design aesthetic inspired by premium wedding venues.

---

## ✨ Features

- 🎥 Fullscreen hero section with background video
- 🖼️ Interactive image gallery with lightbox preview
- 🏛️ Elegant and luxury-inspired UI design
- 📱 Fully responsive layout for mobile, tablet, and desktop
- 🎞️ Smooth scroll animations and reveal effects
- 📍 Detailed venue and contact information section
- 🛏️ Amenities showcase including rooms, parking, rooftop space, and facilities
- 📹 Virtual tour video section
- 💌 Booking enquiry/contact form UI
- 🌙 Modern glassmorphism navigation bar
- ⚡ Clean and organized frontend structure using separate HTML, CSS, and JavaScript files

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Google Fonts
